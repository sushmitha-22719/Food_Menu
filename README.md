🍴 Tasty Bites - Food Ordering App

Tasty Bites is a simple and interactive food ordering web application built using HTML, CSS, and JavaScript. Users can browse the food menu, select their favorite food items, enter their name and quantity, and receive an order confirmation with the total price.

Features
🍕 Food menu display
🍔 Multiple food items
🎨 Attractive user interface
🛒 Order Now functionality
👤 Customer name input
🔢 Quantity selection
💰 Automatic total price calculation
🎉 Order confirmation
Technologies Used
* HTML
* CSS
* JavaScript

This is a beginner-friendly mini project created to practice basic web development concepts.
